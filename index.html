Know Your Money

Every crown gets a job. Nobody else gets a look.

KYM is a zero-based household budget for Android and Basecamp desktop. Your household's phones and computers sync it directly with each other, end-to-end encrypted. There is no server and no cloud account, and nobody holds your finances for you.

What it does

Envelope budgeting, done the careful way.

Zero-based budgeting means you give every crown you have a job before you spend it. When the money in an envelope runs out, you move some over from another one on purpose. KYM keeps the arithmetic honest on every device.

Plan

A monthly grid

Groups and categories with Assigned, Activity and Available for each month. Ready to Assign sits at the top. Moving money between envelopes is one action that always nets to zero.

Accounts

Checking, savings, cards

Credit card spending moves money into a card-payment envelope, so the bill is already covered. Reconcile any account against your bank balance, and KYM books the difference as an adjustment.

Goals

Targets

Give an envelope a monthly funding target and see straight away whether it is funded or how much it still needs.

Households

Several budgets

A budget is a household. Keep yours, a partner's and a shared one side by side. Each has its own colour, the same on every device, and they all sync in the background.

History

Edits never overwrite

Editing or deleting a transaction adds a new entry and keeps the old one. Each change shows the name of the person who made it, so a shared budget can always explain itself.

Currencies

Foreign money, off-budget

A budget has one currency. You can track a euro account as an off-budget tracking account. It counts toward your net worth, not toward Ready to Assign, and there is no hidden FX.

Android the capture app

  • Quick add: amount first, category chips, account and note. Saving takes a few seconds.
  • Receipt scan: on-device text recognition (ML Kit) suggests the amount, merchant and date. It runs on your phone and nothing is uploaded. You confirm before saving.
  • Budget view with assign, targets, reconcile, credit cards and net worth.
  • Review, edit and delete transactions.
  • QR pairing: scan a budget's QR or paste its code. A three-word fingerprint lets you check out loud that both devices hold the same key.

Basecamp the desktop view

  • The full monthly grid, with month-by-month navigation.
  • Accounts, reconciliation, targets and credit card payments.
  • Transaction list with edit and delete, plus author names.
  • Archive or delete categories.
  • Budget switcher. Share a budget with a QR code, or join one by pasting its code.

Command line from the source repo

  • CSV bank import (Air Bank format) with duplicate detection, plus bulk categorise by payee.
  • Reports and net worth.
  • Every budgeting operation, against a budget file that uses the same event log as the apps.
  • A demo of two partners editing offline, then merging to the same result.

How it works & privacy

The budget stays between your devices.

Every change is a small fact, for example "Jana spent 1 240,50 Kč on Groceries". The phone seals it with the household's key and sends it over Logos Delivery, a peer-to-peer messaging network. The other devices in the household open it, add it to their copy of the log and recompute the balances. Balances are never sent; each device calculates them from the facts.

Your household sees

Albert · Groceries−1 240,50 KčChecking · by Jana14 Oct
  • Every transaction, envelope and account, in full.
  • The same balances on every device, because each one does the same calculation.
  • Offline edits from two people merge without losing either change.

The network sees

/kym/1/9f3a61c0e2d84b7a…/proto
7c1e0a9b44f2d1…e83b55c0a7 (sealed)
  • Sealed bytes on a topic name that reveals nothing about the budget.
  • That a message was sent, when, its size, and the sending node's network address.
  • Relays and store nodes can keep sealed messages so devices can catch up later. They can't open them.

One secret per household

Each budget has a random 32-byte secret. The pairing QR carries it from device to device and nothing else ever does. The encryption key and the topic are derived from it.

Sealed with ChaCha20-Poly1305

Every message is authenticated encryption, bound to its topic. Without the household secret you can't read it, and a tampered message is rejected.

A topic derived with HMAC

The topic name is an HMAC of the household key, so two households can't be linked by their topics. It hides the contents, not the fact that traffic happened.

The code is the key

Anyone with a budget's pairing code can read and write that budget, like a shared bank account. Author names show who did what, but they aren't signatures. Share the code only with people and devices you trust.

Optional

An always-on hub, if you want one.

Devices that are online at the same time sync directly with each other. If your household's devices are rarely on at the same time, you can run a headless hub: the same kym_core engine running under logoscore on a machine that stays on. It keeps the full log and fills in gaps for phones and laptops when they reconnect.

There is no public KYM hub. You run your own. A hub is a member of the household: it holds the pairing code and can read the budget, so put it on hardware you control.

How to run a hub →

# on a machine that stays on
git clone https://github.com/vpavlin/kym
cd kym
# set LOGOSCORE + KYM_MODULES_DIR, then:
./hub/kym-hub.sh
# or as a systemd --user service:
cp hub/kym-hub.service ~/.config/systemd/user/
systemctl --user enable --now kym-hub.service

Loam is recommended. Loam runs one shared network node for all your Logos apps, so they don't each run their own. It also adds Bluetooth sync (experimental, Android only). Without Loam, KYM runs its own node.

Basecamp (desktop)

Logos Basecamp 0.2.x · Linux x86_64

  1. In Basecamp, add this under package repositories: https://apps.vpavlin.xyz/logos-repo.json
  2. Install kym (listed as “KYM - Know Your Money”).
  3. That's all. Installing kym also installs its engine, kym_core, and loam_core.

Basecamp 0.3 support is coming. To join a budget you already have, open Share on the phone and enter its pairing code on the desktop, or the other way round.

Status & limitations

Working, and honest about the rough edges.

Works today

  • Phone ↔ desktop sync over Logos Delivery reliable channels, in both directions, tested on real arm64 phones.
  • Budgets merge without conflicts, so concurrent offline edits never cancel each other out. Tests check this with a 200-trial convergence test, and other tests confirm the C++ and TypeScript engines compute the same results.
  • Several budgets per device, edit/delete with author names, and QR sharing on both platforms.
  • A self-hosted headless hub that keeps the log and fills in history for devices that come and go.

Limits & what's next

  • Basecamp 0.2.x only for now; Basecamp 0.3 support is coming. Android is arm64 only, and there is no iOS app.
  • Access is all or nothing per budget. There are no per-person roles and no way to revoke a code. To remove someone, start a new budget.
  • One currency per budget. Foreign accounts are off-budget tracking accounts, with no exchange rates.
  • CSV import and reports are only in the command-line tool so far. Only Air Bank's CSV format is supported.
  • Receipt scanning gives a suggestion you confirm. Its accuracy on real receipts is still being tuned.
  • Network metadata (timing, sizes, addresses) is visible to the network. Bluetooth sync through Loam is experimental and Android only.
