# KYM website

The KYM — Know Your Money website (GitHub Pages). It's one static page, `index.html`, and every path in it is relative, so it works both at `vpavlin.github.io/kym/` and at a domain root. The app source lives on `master`.

Screenshots go in `assets/screens/` (`add.png`, `budget.png`, `review.png`, `scan.png`, `pair.png`, `desktop.png`). The page hides any that are missing.
